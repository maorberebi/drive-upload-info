Privacy Policy

Drive Upload runs only on its owner's computer.

Data accessed

The tool uses the Google Drive scope drive.file. It can access only the files and folders that it created itself in the signed-in user's Google Drive.

How data is used

The tool uses this access only to create folders and to upload, move or list those files at the user's request.

Storage and sharing

The sign-in token is stored only on the user's own computer. The tool has no server, collects no analytics, and does not send or share Google user data with anyone else.

Revoking access

Access can be removed at any time at Google Account permissions.
